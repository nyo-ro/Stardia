# Stardia（スターディア）v0.0.1

小さな学びを、未来につなぐ。汎用学習管理Webアプリの独立した開発版です。

## 起動

Python 3 がある環境で、このリポジトリをカレントディレクトリにして実行します。

```powershell
python -B -m http.server 8765 --bind 127.0.0.1 --directory dist
```

ブラウザで http://127.0.0.1:8765/ を開きます。終了は Ctrl+C。
静的配信だけで動作し、Python APIや既存Studyの起動は不要です。ES Modulesを使うため、HTMLのダブルクリックではなくHTTPで開いてください。

## 現在できること

- 架空の単一プロジェクトのダッシュボード、日別チェックリスト、週表示。
- タスク完了切替、学習記録の追加、時間・日数・内容別集計。
- ライト／ダーク／パープル、アクセント5色、カードの非表示・再表示。
- PC・スマートフォン向けレイアウト。

**学習記録・進捗はメモリ内だけで、再読み込みでリセットされます。実際の学習記録の保存にはまだ使用しないでください。** UI設定だけ `stardia.ui.v1` でlocalStorageに保存します。保存が禁止されている場合は一時表示で動作します。

計画編集、プロジェクト作成、IndexedDB、完全バックアップ・復元、旧JSONインポートは未実装です。

## テスト

Node.js 22以上があれば `npm test` または `node tests/domain.test.mjs`。

```powershell
python -X utf8 -B scripts/verify.py
```

検証スクリプトはNode.js、なければWindowsのVS Code同梱ランタイムを利用します。後者はローカル開発用の代替手段で、アプリの依存ではありません。Chrome/Edgeがあれば `.local/` の専用プロファイルで操作テストを行います。ブラウザがない場合はSKIPと表示します。サーバーはランダムポートでこのリポジトリだけを配信し、終了時に停止します。スマホ幅は390pxのiframe内で検証し、実機検証とは区別します。

## 構成

- `dist/`: 配信する静的ソース。ビルドは不要。
- `dist/src/domain/`: 日付・進捗・集計。DOMや保存先に依存しない。
- `dist/src/storage/`: 非同期RepositoryとUI設定。将来IndexedDBへ差し替える。
- `dist/src/ui/`: 表示用共通処理。
- `tests/`: 架空データによる単体・ブラウザテスト。
- `docs/planning/DEVELOPMENT_BACKLOG.md`: 開発計画。
- `.local/`: Git管理外の検証結果・一時ブラウザプロファイル。

## 開発方針

Studyは読み取り専用の移植元。現行データ・設定・Git履歴は共有しません。外部API、CDN、ログイン、データ送信はありません。開発サーバーを既存Studyのフォルダで実行しないでください。

v0.1はブラウザ保存、完全JSONバックアップ・復元、単一プロジェクトの計画・記録・進捗管理を目標にします。内部のprojectIdと保存境界を活かし、自由分類・階層・テンプレートは後から追加します。GitHub Pagesへ配置する場合は `dist/` のみが対象。remote・公開設定はまだありません。

ブラウザ保存は端末・オリジン単位です。将来はバックアップ導線も提供します。個人データ・機密情報をテストや公開物へ追加しないでください。
